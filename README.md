# Adha Tour & Travel — React + Vite

Struktur sudah dipecah menjadi:
- `src/components` untuk UI
- `src/data` untuk data paket, fasilitas, tour, testimoni
- `src/styles` untuk CSS

## Menjalankan
```bash
npm install
npm run dev
```

## Facility icon
Warna icon fasilitas ada di:
`src/styles/components.css`

Class:
`.facility .icon`
dan:
`.facility:hover .icon`
